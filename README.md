# Fourmiz

Simulation tactile de colonie en HTML et Canvas. Cette première version indépendante s’inspire des expériences menées par Mathieu dans AntSimu. Son code et ses graphismes sont propres à Fourmiz.

Ouvrir `index.html` dans un navigateur moderne. Le fichier est autonome et fonctionne hors ligne.

Touchez le terrain pour ajouter des graines à un endroit précis. Les ouvrières explorent, transportent les graines et marquent leur chemin de retour. Les exploratrices peuvent suivre ces pistes et les butineuses se souviennent temporairement d’une source. La réserve finance la ponte et la maturation des larves. Les commandes permettent de masquer les pistes, de mettre en pause ou de passer en vitesse ×2 ou ×4.
